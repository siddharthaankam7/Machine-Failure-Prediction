Machine Failure Prediction Using Five Machine Learning Algorithms
This project predicts machine failures using machine learning techniques and the AI4I 2020 Predictive Maintenance Dataset.

Algorithms Used:
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest
5. Support Vector Machine (SVM)
Technologies Used: Python, Pandas, Matplotlib, and Scikit-learn.

Project Objective: To analyze machine data, train multiple machine learning models, compare their performance, and predict potential machine failures.
